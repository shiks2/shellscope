ShellScope: The Local Flight Recorder for Windows.

Capture transient processes and terminal activity under 100ms using WMI. Zero cloud dependencies. Logs command-line arguments to local SQLite DB.

View on GitHub

About ShellScope

ShellScope uses Windows Management Instrumentation (WMI) to capture process creation events, including short-lived "flash" processes (<100ms). Provides audit trail without external dependencies.

Highlights

Highlights: Process List (Green: safe, Red: suspicious like -enc), Status (Running/Closed), Real-time dashboard.

Core Features

Transient Process Capture

Detects/logs processes <100ms lifespan.

Argument Logging

Captures full command-line args for analysis.

Local-First Architecture

SQLite storage, no cloud uploads.

Low Resource Usage

Python WMI backend + performant Flutter UI.

Installation

Prerequisites: Python 3.8+, Flutter SDK, Windows OS.

  1. 1. git clone https://github.com/shiks2/shellscope.git
  2. 2. cd shellscope
  3. 3. pip install wmi pywin32
  4. 4. flutter run -d windows
