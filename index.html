About ShellScope

ShellScope uses Windows Management Instrumentation (WMI) to capture process creation events, including short-lived "flash" processes (<100ms). Provides audit trail without external dependencies.

A local flight recorder for Windows terminal activity and transient process logging. Highlights: Process List (Green: safe, Red: suspicious like -enc), Status (Running/Closed), Real-time dashboard.

Key Features

Transient Process Capture

Detects and logs processes with lifespans <100ms.

Argument Logging

Captures full command-line args for detailed analysis.

Local-First Architecture

All data is stored locally in SQLite with no cloud uploads.

Low Resource Usage

Efficient Python WMI backend combined with a performant Flutter UI.

Installation

Prerequisites

  • Python 3.8+
  • Flutter SDK
  • Windows OS

Steps

  1. git clone https://github.com/shiks2/shellscope.git
  2. cd shellscope
  3. pip install wmi pywin32
  4. flutter run -d windows

Usage Guide

Dashboard shows real-time activity: Process List (Green safe/Red suspicious), Status Indicator (Running/Closed).

The ShellScope dashboard provides a real-time view of system activity, helping teams investigate suspicious command execution patterns and short-lived terminal events.
